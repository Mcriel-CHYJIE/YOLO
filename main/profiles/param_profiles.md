# 摔倒检测 YOLO 训练参数三套方案 (yolo11n + RTX 5070 Ti 16GB)

基于 `D:\Projects\11_fall\YOLO\main\project.yaml`，三套不同倾向的参数配置。

---

## 方案 A：高精度低误报（生产部署推荐）

> 误报率最低，适合监控告警场景，报警即处理，宁可漏报不可谎报。

| 参数 | 值 | 说明 |
|------|------|------|
| **batch** | 64 | yolo11n 轻量，RTX 5070 Ti 可容 |
| **cls_pw** | 0.5 | 正类权重压低 → 模型保守，需强证据才判正 |
| **iou** | 0.8 | 严格 NMS → 重叠冗余框减少 |
| **conf (val/predict)** | 0.55 | 推理阈值高 → 低分框直接过滤 |
| **close_mosaic** | 15 | 提前关 Mosaic，防混合姿态混淆 |
| **copy_paste** | 0.05 | 摔倒人体粘贴易不自然，极少量即可 |
| **degrees** | 2.0 | 摔倒方向性极强，仅微小旋转 |
| **scale** | 0.3 | 摔倒人体尺度较一致，缩小增强范围 |
| **hsv_h** | 0.01 | 衣着颜色变化有限，小色相扰动 |
| **flip_lr** | 0.3 | 摔倒可能有左右不对称，降低翻转 |
| **flipud** | 0.0 | 保持关闭，上下翻转产生假样本 |
| **mosaic** | 1.0 | 标准 mosaic |
| **mixup** | 0.2 | 标准 mixup |

**适用场景**：养老院监控、工厂安全、家庭看护——误报会导致人员麻木，宁可漏一次不能误十次。

---

## 方案 B：高召回率（安全覆盖推荐）

> 宁可误报不可漏报，适合安全审查场景，事后回溯查漏补缺。

| 参数 | 值 | 说明 |
|------|------|------|
| **batch** | 64 | 同设备 |
| **cls_pw** | 1.0 | 正类权重平衡 → 模型不偏不倚 |
| **iou** | 0.7 | 宽松 NMS → 多框覆盖，宁可重叠不可漏 |
| **conf (val/predict)** | 0.35 | 推理阈值低 → 弱信号也触发 |
| **close_mosaic** | 30 | 延长 Mosaic → 更多混合样本增强泛化 |
| **copy_paste** | 0.2 | 更多复制粘贴增强 → 丰富摔倒姿态 |
| **degrees** | 5.0 | 适度旋转 → 覆盖不同角度的摔倒 |
| **scale** | 0.6 | 大范围缩放 → 适应不同距离的摔倒 |
| **hsv_h** | 0.015 | 适度色相扰动 |
| **flip_lr** | 0.5 | 标准左右翻转 |
| **flipud** | 0.0 | 保持关闭（摔倒有方向性） |
| **mosaic** | 1.0 | 标准 mosaic |
| **mixup** | 0.3 | 更高 mixup → 丰富样本多样性 |

**适用场景**：安防审查回放、全量记录分析、实验室 benchmark——漏报成本极高，略多误报可接受。

---

## 方案 C：均衡型（通用默认）

> 精度与召回兼顾，适合迭代调试和通用场景，无明显倾向。

| 参数 | 值 | 说明 |
|------|------|------|
| **batch** | 64 | 同设备 |
| **cls_pw** | 0.7 | 适度压低 → 控制误报但不过度 |
| **iou** | 0.75 | 中等 NMS |
| **conf (val/predict)** | 0.45 | 中等推理阈值 |
| **close_mosaic** | 20 | 适中 |
| **copy_paste** | 0.12 | 适度复制增强 |
| **degrees** | 3.0 | 小旋转 |
| **scale** | 0.45 | 适中缩放 |
| **hsv_h** | 0.012 | 适中色相 |
| **flip_lr** | 0.4 | 适中翻转 |
| **flipud** | 0.0 | 保持关闭 |
| **mosaic** | 1.0 | 标准 mosaic |
| **mixup** | 0.2 | 标准 mixup |

**适用场景**：日常训练调试、新数据验证、快速迭代原型——平衡各项指标。

---

## 参数三维对比

| 维度 | 方案 A (高精度) | 方案 B (高召回) | 方案 C (均衡) |
|------|:---:|:---:|:---:|
| cls_pw | 0.5 | 1.0 | 0.7 |
| iou | 0.8 | 0.7 | 0.75 |
| conf | 0.55 | 0.35 | 0.45 |
| 误报倾向 | ⭐⭐⭐ 最低 | ⭐ 较高 | ⭐⭐ 中等 |
| 漏报倾向 | ⭐ 较高 | ⭐⭐⭐ 最低 | ⭐⭐ 中等 |
| 增强强度 | 保守 | 激进 | 中等 |

## 使用方式

切换到项目目录，将对应方案的值填入 `main/project.yaml` 的 `training:` 和 `validation:`/`predict:` 段落后，用 UI 启动训练即可。

或直接在训练 Tab 中手动调节对应 SpinBox/ComboBox 的值。
